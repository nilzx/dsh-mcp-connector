# MCP 连接器

把 MCP 服务器接到 DeepSeek Harness 里，让智能体能直接使用它们的工具。支持本地命令、远程地址和 OAuth 登录，并且可以为每个工具单独设置智能体能做什么。

English: [README.md](README.md)

## 开始之前

- 已安装 DeepSeek Harness（dsh）。
- 如果服务器是本地命令，需要先装好对应的命令（例如 `npx`）。

## 安装

1. 打开 **设置 → 插件**。
2. 选择 **添加插件**，填入 `@nilzx/dsh-mcp-connector`。
3. 安装完成后，**设置** 左侧会多出 **MCP 连接器** 一页。

> 也可以在终端运行 `dsh plugin add @nilzx/dsh-mcp-connector`。安装后如果页面里没看到，刷新一次页面或重启 Harness。

## 添加服务器

打开 **设置 → MCP 连接器**，点 **添加服务器**：

1. 起一个名字，例如 `github`。这个名字会出现在工具名里，之后不要随意改。
2. 选择连接方式：
   - **本地进程**：填写命令；参数（每行一个）和环境变量在 **更多连接设置** 里。
   - **远程端点**：填写服务器地址，例如 `https://mcp.example.com/mcp`。
3. 如果服务器需要密钥，在 **更多连接设置** 里填写环境变量或请求头；也可以先在凭据里保存，再引用为 `${credential:名称}`。
4. 按 **回车** 或离开输入框：配置会保存并重连。卡片变成 **已连接**，并列出发现的工具。

保存后，智能体就能看到名为 `mcp__github__<工具>` 的工具。直接对它说“用 github 工具看看仓库里有哪些 issue”即可。

## 点开一个服务器之后

展开服务器会看到三个子标签页：

- **连接**（默认打开）——名称、连接方式、登录方式，以及可选的连接设置。
- **权限**——默认权限，以及每个已发现工具单独一行。
- **其他**——作用范围，以及是否允许临时子代理使用。

## 登录需要 OAuth 的服务器

很多远程 MCP 服务器（例如 Linear、Notion 一类的服务）通过 OAuth 登录：

1. 在 **连接** 页把 **登录方式** 设为 **OAuth 登录**。授权范围、客户端 ID、回调端口等可选字段收在 **OAuth 选项** 里，通常留空即可。
2. 卡片会变成 **需要登录**，并在浏览器里打开授权页面。
3. 同意后回到 Harness，状态变成 **已连接**。

登录信息保存在本机，重启不需要重新登录。想换账号时点 **忘记登录**，再重新登录。如果浏览器没有自动打开，点击卡片里的 **打开登录页面**。

## 设置每个工具能做什么

打开服务器的 **权限** 子标签页。每个已连接的服务器会列出它的工具，每个工具可以选：

| 权限 | 效果 |
|---|---|
| **默认** | 跟随该服务器的默认设置。 |
| **允许** | 直接执行。 |
| **询问** | 每次调用都先弹窗确认。 |
| **禁止** | 直接拒绝，不会执行。 |
| **隐藏** | 不提供给智能体，它根本看不到。 |

第一行是“其余工具的默认权限”。**按模式匹配的规则**（例如 `delete_*`）用于服务器尚未列出的工具，按顺序匹配，先命中的生效。

这些规则只影响智能体调用，不影响服务器本身。

## 选择服务器的作用范围

打开服务器的 **其他** 子标签页：

- **全局（所有会话）**——默认，所有会话都能使用这些工具。
- **仅在指定工作区**——只有在所选目录中运行的会话才会看到这些工具。

适合按项目使用的服务器：把工作用的服务器隔离在个人会话之外，或者把同一个服务的两个账号分别接到不同项目。

**临时子代理** 也在这里。个人记忆这类只属于主会话的服务可以设为 **禁止访问**，子代理就看不到也调用不了它的工具；主会话的分叉仍可访问。

通过 YAML 配置的高级能力（逐轮上下文刷新、可信会话元数据、初始化流程等）见 [高级配置](docs/ADVANCED.zh.md)。这些能力尚未发布，也不在设置面板中。

## 什么时候保存

- 勾选框和下拉菜单在改动后立即保存。
- 文本输入按 **回车** 或离开输入框时保存，所以半截地址不会被提交。
- 删除服务器、规则或某一行会立即保存。
- 新增的空服务器、空规则或空行，在填写完成前不会保存。

头部会显示配置是已保存、保存中、有未保存的修改，还是不完整。不完整的配置不会被写入。

## 连接状态

| 状态 | 含义 |
|---|---|
| 已连接 | 工具可用。 |
| 连接中 / 重连中 | 正在尝试连接，稍等即可。 |
| 需要登录 | 等你在浏览器里完成登录。 |
| 失败 | 多次重试仍失败；修好后点 **重连**。 |
| 已停用 | 配置保留但暂不连接。 |

## 常见问题

**连不上怎么办？** 展开卡片看最近一次错误。本地进程常见原因是命令写错或缺少依赖；远程端点常见原因是地址不对、网络不通或需要登录。修好后点 **重连**。

**地址里没有路径。** 很多服务的 MCP 端点在 `/mcp`、`/ds/mcp` 这样的路径上，只填域名通常会返回 404，也不会发起登录。请从服务那里复制完整端点。

**智能体看不到工具？** 确认服务器是 **已连接**，并且在 **权限** 页里不是 **隐藏** 或 **禁止**。新建一个会话会重新读取工具列表。

**修改没有生效？** 在输入框里按 **回车** 或离开输入框；勾选框和下拉菜单会自己保存。如果头部一直显示失败，点 **重新加载** 再试。还不行可以停用再启用这个插件。

**登录一直失败？** 点 **忘记登录**，再点 **登录**，会得到一条全新的登录链接。

## 隐私与安全

- 工具调用的参数会发送到你配置的服务器，结果会回到当前会话。只连接你信任的服务器。
- 对会修改远端数据的工具，建议使用 **询问** 或 **禁止**。
- 登录凭据保存在本机，不会写进配置文件。
